# 🏪 Retail Store Sales EDA

## 📌 Project Overview

This project performs **Exploratory Data Analysis (EDA)** on a Retail Store Sales dataset.

The main goal of this project is to understand the dataset, check data quality, analyze sales patterns, identify relationships between variables, and generate meaningful business insights.

---

# 🎯 Project Objective

The objectives of this project are:

- Understand the dataset structure.
- Perform data quality checks.
- Identify missing values and duplicate records.
- Clean and prepare the dataset.
- Perform statistical analysis.
- Analyze sales distribution.
- Identify outliers.
- Perform correlation analysis.
- Analyze the relationship between Sales and Price.
- Analyze discount distribution.
- Identify the category with the highest sales.
- Generate meaningful insights from the data.

---

# 📂 Dataset

The dataset contains retail transaction information.

## Dataset Features

| Column | Description |
|---|---|
| Transaction_ID | Unique ID for each transaction |
| Age | Age of the customer |
| Quantity | Number of products purchased |
| Price | Price of the product |
| Discount_Percent | Discount percentage applied |
| Sales | Total sales amount |
| Category | Product category |
